# AGENTS.md

## What this repo is

A browsable React pattern/component library (`react-toolbox`). The code **is** the documentation — no MDX, no prose docs. Each pattern is a self-contained `.tsx` file that renders a live interactive demo. View in browser, copy-paste the code.

## Commands

```bash
npm run dev           # Vite dev server (SPA only, no SSR)
npm run build         # vite build only — NOT tsc first (see below)
npm run typecheck     # tsc -b — run separately, after build generates routeTree.gen.ts
npm run lint          # oxlint
npm run format        # oxfmt src — format all files in src/
npm run format:check  # check formatting without writing
npm run preview       # preview the dist build
```

## Critical: build order

`routeTree.gen.ts` is **auto-generated by the TanStack Router Vite plugin** on the first `vite build` or `vite dev` run. It does not exist on a fresh clone.

- `npm run build` runs `vite build` only — correct
- `npm run typecheck` (`tsc -b`) will **fail on a fresh clone** until `vite build` or `vite dev` has run once to generate `routeTree.gen.ts`
- Never change `build` back to `tsc -b && vite build` — tsc will error because the generated file doesn't exist yet

## Adding a pattern

Two steps, nothing else needed:

1. Create `src/patterns/<category>/<name>.tsx` with a default export React component
2. Add an entry to `PATTERNS` array in `src/lib/patterns.ts`

The sidebar, routing, and lazy loading all update automatically. No route files to create.

**Pattern slug encoding:** slugs use `--` instead of `/` in the URL (e.g. `form/basic` → `/patterns/form--basic`). The `$slug.tsx` route decodes `--` back to `/` via `slug.replace('--', '/')`.

## Pattern loading mechanism

```ts
// src/routes/patterns/$slug.tsx
const patternModules = import.meta.glob('../../patterns/**/*.tsx')
```

Vite requires the glob path to be **statically analyzable**. Never use a variable in the import path (e.g. `` import(`../patterns/${slug}.tsx`) `` will fail with "Unknown variable dynamic import"). The glob map approach is the correct solution.

## shadcn components

**Style:** `radix-mira`, base color `neutral`, preset `b1D0dv96`. The near-black primary button and minimal aesthetic are **intentional** — do not fight the theme.

**Adding components:**
```bash
npx shadcn@latest add <component-name>
```

**Re-initializing:** shadcn CLI needs `src/index.css` to contain at least `@import "tailwindcss";` to detect Tailwind. If `index.css` is missing, the CLI will error. Use `--force --reinstall` to avoid interactive prompts:
```bash
npx shadcn@latest init --preset b1D0dv96 --template vite --force --reinstall
```

**Never hand-edit `src/components/ui/`** — those files are owned by the shadcn CLI.

## CSS / theming

`src/index.css` uses Tailwind v4 with raw `oklch()` color values (not `hsl()`). The `@theme inline` block maps CSS vars to Tailwind color tokens.

- Do **not** add `hsl(var(--border))` style rules — the vars are already `oklch()` values, wrapping them in `hsl()` produces black fallbacks
- `@layer base` applies `border-border`, `bg-background`, `text-foreground`, `font-sans` globally — don't duplicate these in manual CSS
- To override shadcn component styles **without editing `src/components/ui/`**, use `data-slot` attribute selectors in `@layer components` in `index.css`. Every shadcn component sets `data-slot="<name>"` (e.g. `data-slot="input"`, `data-slot="button"`). Use `!important` — Tailwind utility classes outrank `@layer components` without it

## TypeScript

- `tsconfig.app.json` has `"ignoreDeprecations": "6.0"` — required because TypeScript 6 deprecates `baseUrl`. Don't remove it.
- `tsconfig.json` (root) also has `compilerOptions.paths` — required because the shadcn CLI reads the root tsconfig, not `tsconfig.app.json`, when validating the import alias.

## Key files

| File | Purpose |
|---|---|
| `src/lib/patterns.ts` | Single registry of all patterns — the only place to add/remove patterns |
| `src/routes/__root.tsx` | Root layout: sidebar + `<Outlet />` |
| `src/routes/patterns/$slug.tsx` | Pattern viewer: glob loader, header, preview area |
| `src/routes/index.tsx` | Redirects to `/patterns/form--basic` |
| `src/routeTree.gen.ts` | Auto-generated — do not edit |
| `components.json` | shadcn config |
| `vite.config.ts` | TanStack Router plugin must be listed **before** react plugin |
